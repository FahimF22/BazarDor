# 🛒 বাজার দর | Bazar Dor

**প্রয়োজনীয় পণ্যের দাম এক নজরে** — বাংলাদেশের বাজার দর ট্র্যাকার।

## ✨ Key Features

1. **রিয়েল-টাইম প্রাইস ট্র্যাকিং** — আজকের দাম, ▲/▼ পরিবর্তন, বাজারভিত্তিক min/max
2. **প্রাইস টিকার (Marquee)** — ন্যাভবারের নিচে অনন্ত স্ক্রলিং প্রাইস স্ট্রিপ
3. **ক্যাটাগরি ফিল্টার + সর্ট** — দাম কম→বেশি / বেশি→কম (বাংলা সংখ্যা সাপোর্ট)
4. **প্রোডাক্ট ডিটেইল** — সুরক্ষিত রুট, মার্কেট টেবিল, min/max/avg
5. **BetterAuth অথেন্টিকেশন** — ইমেইল/পাসওয়ার্ড + Google/GitHub সোশ্যাল লগইন
6. **প্রোফাইল আপডেট** — নাম আপডেট করার সুবিধা
7. **রেসপন্সিভ ডিজাইন** — মোবাইল, ট্যাবলেট, ডেস্কটপ
8. **লোডিং স্কেলেটন + টোস্ট + ৪০৪ পেজ**

## 🛠️ Technologies

- Next.js (App Router)
- TypeScript
- Tailwind CSS + DaisyUI
- BetterAuth
- react-hot-toast
- Programming Hero Open API

## 🚀 Getting Started

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000
